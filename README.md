# CS

## The Daily Compute

One real computing story a day for learners aged 10–14, with discussion points, key words, a quiz, a Four Links game and a code puzzle. Activities link to the Curriculum for Excellence Technologies experiences and outcomes (Second and Third level).

- Site: https://bwclark14.github.io/CS/daily-compute/
- `daily-compute/index.html`: the page
- `daily-compute/stories.json`: every published story and its activities
- `tools/daily-compute/`: the checker the daily tasks use before saving or publishing a story

New stories are drafted each evening, approved by a teacher, then published here each morning by a scheduled task. Please don't edit `stories.json` by hand while a publish might be running.

## The Data Trail

An interactive unit for learners aged 13–15 on how AI uses data from social media, web browsing and online shopping to influence behaviour. Six parts with simulations, video clips, real news case files and a quiz, ending with a team project, The Algorithm Audit.

- Site: https://bwclark14.github.io/CS/data-trail/
- `data-trail/index.html`: the whole resource in one self-contained page

A second version adds rule-based vs data-driven systems, data poisoning, accessibility and the energy cost of AI, training and test data in CV-Bot, and a Scotland lens for the project.

- Site: https://bwclark14.github.io/CS/data-trail-2/
- `data-trail-2/index.html`: the second version
- `data-trail-2/sites/`: three practice apps for the Practice audit activity, all simulated: Loop (social media), Bargo (online shop) and Starforge (mobile game). Each has built-in data, privacy and dark-pattern issues for pupils to find; the answer key is in the teacher notes.

Version 3 adds a more balanced view, showing when data and AI genuinely help as well as when they harm. New activities: device fingerprinting, Worth the trade? cards, writing a recommendation recipe, retraining a feed out of a filter bubble, and a positive case file on AI that spots eye disease.

- Site: https://bwclark14.github.io/CS/data-trail-3/
- `data-trail-3/index.html`: version 3
- `data-trail-3/sites/`: copies of the three practice apps for version 3

## Future Proof

An interactive unit for learners aged 13–15: past predictions, present tech and future frontiers. Five parts: how computers think and talk (a fetch–decode–execute simulator, the memory hierarchy, packet switching and bandwidth), retro futures (archive Tomorrow's World clips, a prediction lab, misquotes and an evaluation matrix), smart tech with the BBC micro:bit (a two-board radio simulator plus MakeCode and MicroPython code for real hardware), frontier tech (AI, quantum, brain–computer interfaces, green computing, spotting hype) and a pitch with a five-year time capsule. Ends with a team project, The 2031 Broadcast.

- Site: https://bwclark14.github.io/CS/future-proof/
- `future-proof/index.html`: the whole resource in one self-contained page
- `future-proof/src/`: the source pieces; run `sh future-proof/src/build.sh` to rebuild `index.html` after editing them

Time capsule files are plain JSON, optionally encrypted in the browser with a class passphrase. The teacher notes include a tool to open them.
