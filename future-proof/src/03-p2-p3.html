Patterns to look for

  • Predictions about what people want (to talk, shop, find their way) often come true. Predictions about how it will look often don’t.
  • Many “hits” arrived 20–30 years late, once processing power, memory, batteries and networks caught up.

2.5 · CASE FILE

The time capsule nobody could open

In 1986 the BBC made a digital “Domesday Book” to mark 900 years since the original. It should have been a gift to the future. Within about fifteen years, almost nobody could read it.

1086The original Domesday Book records England. It is written on parchment and can still be read today.
1984–86Schoolchildren and members of the public across the UK write about their local area. Around a million people take part. Acorn, Philips, Logica and the BBC build the system.
1986It is published on special laser discs that need a Philips player connected to a BBC Master computer.
~2000The players and computers are obsolete. Very few still work and the discs are starting to decay. Paper from 1086 is easier to read than discs from 1986.
2002–2010Volunteers and researchers rescue the data, repair a working system and copy everything. An online version follows in 2010.

Why this matters for your time capsule

In Part 5 you will seal a prediction to open in five years. Digital files only survive if something can still read them. That needs the file format, the software, the storage and, if you encrypt it, the key.

Discuss

  • Which file format would you trust to still open in 2031: a .txt file, a .docx, a phone video, or a page on a website? Why?
  • Who should be responsible for keeping digital things readable: the person who made them, the company, or libraries and museums?
  • Name something you’ve made that you might not be able to open in five years.

Digital obsolescence: when data still exists, but the hardware or software needed to read it doesn’t.

PART 3 OF 5

Smart tech with the micro:bit

The 1989 “home of the future” is now called the Internet of Things: everyday objects with sensors, a small processor and a network connection. You’re going to build one. Use the simulator first, then build it for real on BBC micro:bits.

3.1 · HOW A SMART DEVICE WORKS

Sense, decide, send, act

Every smart device, from a doorbell to a fitness tracker, does the same four jobs. The micro:bit can do all four.

INPUTSenseA sensor measures the real world: light, temperature, movement, sound.
PROCESSDecideThe processor compares the reading with a rule, like “if it’s darker than 50…”.
COMMUNICATESendA radio sends a message to another device, often across a network.
OUTPUTActThe receiving device does something: shows an icon, sounds an alarm, logs the data.
Light sensorUses the LEDs. Reads 0 (dark) to 255 (bright).
TemperatureReads the processor’s temperature in °C, close to the room temperature.
AccelerometerMeasures movement and tilt. Detects shakes, so it can count steps.
RadioSends short messages to other micro:bits nearby. Only micro:bits on the same radio group hear them.

3.3 · BUILD IT FOR REAL

Build your prototype

Work in pairs: one person programs the sensor, the other the receiver. The code below updates to match the scenario and threshold you chose in the simulator.

2 × BBC micro:bitV1 or V2. V2 adds a speaker and microphone.
2 × USB cableOr battery packs once the code is on.
A browserMakeCode at makecode.microbit.org, or the Python editor at python.microbit.org.
Optional extrasSoil moisture sensor, PIR motion sensor or LEDs on crocodile clips.
  1. Agree a radio group number with your partner (0–255). Use one nobody else in the room is using, or your messages will mix.
  2. Open the editor, choose JavaScript or Python, and paste in the sensor code or the receiver code. Change the group number to yours.
  3. Test in the editor’s on-screen simulator first. Then download and copy the .hex file to the micro:bit (or use WebUSB to flash it directly).
  4. Test with real readings: cover the light sensor, warm the micro:bit in your hand, or shake it. Write down the readings so you can choose a sensible threshold.
  5. Improve it. Pick one: send the actual reading, not just an alert; add a “cancel” message with button B; make the receiver keep a count; or add the scrambling extension.

    3.4 · SMART BUT SAFE?
    
When things join the internet, so do hackers

    
Your micro:bits only talk across a room. Real smart devices talk across the internet, which means anyone, anywhere, might try to talk to them too.

  

  

    
The law changed in 2024

      
Since 29 April 2024, UK law (the Product Security and Telecommunications Infrastructure Act) says smart devices sold here must:

      
    
        
  • not come with an easy default password like “admin” or “12345”,
    • 
        
  • tell you how to report a security problem,
    • 
        
  • say how long the device will get security updates.
    • 
      

      
The UK was the first country to bring in rules like these.
